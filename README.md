# 1-5 수행평가 및 학급 기사 사이트

스케치하신 레이아웃 구도를 그대로 구현한 학급 대시보드 웹사이트입니다.

## 주요 기능
1. **상단 좌측 (1-5 수행평가 목록)**: 수행평가 내용 추가, 일정순/과목별 정렬 지원
2. **상단 우측 (일정)**: 수행평가가 있는 날에 푸른색 표시(●)
3. **하단 (1-5 기사)**: 기사 내용 및 작성자/날짜 입력 기능

## 실행 및 업로드
- `index.html`을 클릭하면 브라우저에서 바로 실행됩니다.
- GitHub 저장소에 이 폴더 안의 파일들을 올려서 GitHub Pages로 사용할 수 있습니다.
